# OfficeFlow AI — Complete Build Prompts

> A sequential prompt pack for building the OfficeFlow AI hackathon project as a **single Next.js + Node.js application deployable on Vercel**.
>
> **Recommended order:** Prompt 0 → 1 → 2 → ... → 17.
>
> **Important:** Do not give all prompts to a coding agent at once. Run them sequentially and commit after successful phases.
